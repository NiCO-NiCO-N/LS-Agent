# 数据分析

## 适用场景

用户提供 CSV/文本数据，要求「分析一下 / 看看趋势 / 做个统计」时使用。

## 步骤

1. 用 `list_dir` 找到数据文件，`read_file` 读取前几十行确认列名和分隔符。
2. 调用 `run_skill_script`，技能 `data-analyst`、脚本 `quick_stats.py`，参数为数据文件的相对路径：

   ```json
   {"skill": "data-analyst", "script": "quick_stats.py", "args": ["data/sales.csv"]}
   ```

   脚本会输出行数、每列的缺失值、数值列的最小/最大/均值/中位数、类别列的高频取值。
3. 需要更复杂的处理时，用 `run_python` 自己写代码（只能操作 workspace 内的文件）。
4. 输出结论：数据质量如何、最值得注意的 3 个事实、建议的下一步分析。

## 输出结构

```
## 数据概览
- 行数 / 列数 / 时间范围

## 数据质量
- 缺失、重复、异常值

## 关键发现
1. …
2. …

## 建议
- 下一步该看什么、用什么图
```

## 约束

- 样本量小于 30 时，不要下强结论。
- 相关不等于因果，措辞要谨慎。
- 不要编造没有出现在数据里的数字。
